# 完整方法：归一化、细线误差、概率几何和解释闭环

本文同时记录**当前可执行原型**和**完整科学验证协议**。数学定义描述的是最终方法；每节的“当前状态”用来防止把未接线模块或尚未做的真实数据实验误读为已完成结果。总览见 [`README.md`](../README.md)。

## 1. 是否归一化到 `[-1,1]^2`

结论是**需要**，但这里的 `[-1,1]^2` 只描述网络的观测画布，不是髓心标签的取值边界。

必须分开两类归一化：

1. **光度归一化**：RGB 转为 `[0,1]`，再按训练集均值/标准差变换；只改变像素值。
2. **几何归一化**：同一个可逆变换作用于图像采样、年轮点、髓心、节源、协方差、弧长和曲率。

对 `W x H` 原图，采用各向同性尺度：

\[
\mathbf m=((W-1)/2,(H-1)/2),\quad L=\max(W,H)/2,
\]

\[
\widetilde{\mathbf x}=(\mathbf x-\mathbf m)/L.
\]

长边的连续图像边界为 `[-1,1]`，短边居中并由 `valid_mask` 标记 padding。像素中心采用 `align_corners=False`，与 [DSNT](https://arxiv.org/abs/1801.07372) 的规范坐标约定一致。

这只是可逆的换单位：它改善优化条件数、让跨分辨率的超参数有统一量纲，但不会凭空增加弧的曲率信息，也不会把不可辨识的近平行短弧变成可辨识。DSNT 的规范坐标可作为坐标约定参考，但热图期望仍受画布支持限制，不能用来承载任意远的图外髓心。

按图像 `L` 归一会隐藏绝对物理尺度。工程始终保留 `L_px`/`scale_px` 和 `mm_per_pixel`；若轮宽、节核或平滑先验依赖毫米尺度，还应把物理尺度作为模型条件量或直接在毫米坐标中定义先验，不能把不同采集尺度下相同的规范宽度当作相同生物宽度。

### 为什么不能分别缩放 x 和 y

若把非方形图的 x/y 独立拉伸到 `[-1,1]`，圆会变椭圆，夹角、法线、曲率和距离都会改变；模型将无法区分真实斜切椭圆与预处理产生的椭圆。等比例缩放＋padding 保留欧氏几何。

### 图外髓心如何处理

所有有限真值先用同一变换：

\[
\widetilde{\mathbf c}=(\mathbf c-\mathbf m)/L\in\mathbb R^2.
\]

不 clip、不投影到边框、不对完整坐标使用 `tanh`。只有近场 mixture 的数值支持限制在重叠区域；远场使用方向—逆距离，不丢失图外真值。

网络规范空间到原图的逆变换始终保留，因此最终输出可以是 `(-1834.4,706.2)` 像素，而不是伪造的边界点。

## 2. 年轮、方向、误差和增强如何同步变换

各向同性尺度下：

| 几何量 | 变换 |
|---|---|
| 点、控制点、髓心、扰动源 | `(x-m)/L` |
| 半径、线宽、SDF、弧长、轮间距 | 除以 `L` |
| 点协方差 | `Sigma/L^2` |
| 曲率 | `kappa_norm=L*kappa_px` |
| 切线/法线 | 尺度不变，随旋转变换 |
| Fourier 角度、年轮编号、拓扑 | 不变 |

对一般仿射矩阵 `A`：

\[
\mathbf t'\propto A\mathbf t,\quad
\mathbf n'\propto A^{-T}\mathbf n,\quad
\Sigma'=A\Sigma A^T.
\]

增强时先变换 polyline、髓心和协方差，再在最终分辨率重新软栅格化。不要旋转/缩放 1 px 硬 mask：它会断裂、重影或人为变粗。

若相似变换为 `g(x)=sRx+t`，髓心和弧点都用 `g`；再相对新锚点重算方向和逆距离。对几何逆距离 `rho=1/d`，纯旋转时 `n'=Rn, rho'=rho`，尺度增强时 `rho'=rho/s`。网络使用的无量纲 `eta_net=r_switch/d` 在固定 `r_switch` 下具有同样的尺度变换。任意平移不能只旋转方向，必须变换髓心和参考点后重算。

**物理尺度边界。** 若 `mm_per_pixel_x=mm_per_pixel_y`，`scripts/03_infer.py` 可通过 `MM_PER_PIXEL=(X, Y)` 在逆变换后报告毫米坐标。若二者不等，必须先在物理等比尺度上重采样；`CoordinateFrame` 会显式拒绝未矫正的各向异性物理像素，避免在错误欧氏度量下静默拟合。

## 3. 近场、远场、无穷远和拒识

近场使用二维笛卡尔 mixture：

\[
M_N:\quad p(\mathbf c)=\sum_j\pi_j\mathcal N(\mu_j,\Sigma_j).
\]

几何 refiner、Schur 信息和输出 JSON 使用真正的逆距离：

\[
\mathbf n=\frac{\mathbf c}{\|\mathbf c\|},\qquad
\rho=\frac1{\|\mathbf c\|}.
\]

神经远场头为使远场支持落在稳定区间，使用另一个无量纲变量：

\[
\eta_{net}=\frac{r_{switch}}{\|\mathbf c\|}=r_{switch}\rho.
\]

因此网络输出的 `eta_net` 不能直接当作 JSON 的 `inverse_distance`；候选生成时先按 `r_switch` 转回笛卡尔坐标，几何优化再报告 `rho`。

- `rho>0`：有限髓心；
- `rho -> 0`：越来越远；
- `rho=0`：当前数据只支持方向；
- `null`：方向也不支持。

这种紧化思想来自 [Unified Inverse Depth Parametrization](https://webdiis.unizar.es/~josemari/rss2006.pdf)。它提供稳定参数化，但不是“短弧必然能恢复远距离”的证明。

### 远场残差不构造巨大坐标

令 `c=n/rho`，圆半径写为 `R_k=1/rho+beta_k`。对原始距离残差有精确有理化：

\[
e_k(\mathbf x)=
\frac{\rho\|\mathbf x\|^2-2\mathbf n^T\mathbf x}
{\|\rho\mathbf x-\mathbf n\|+1}-\beta_k.
\]

当 `rho=0`：

\[
e_k(\mathbf x)=-\mathbf n^T\mathbf x-\beta_k,
\]

自然退化为平行层。代码直接实现这一公式及梯度，因此不会因先生成 `n/rho` 而发生溢出或虚假 Hessian。

无向切线具有 `n` 与 `-n` 二义性，多起点必须保留两个方向；方向后验可以双峰。

**状态后验语义。** `neural_state_probabilities` 是密集/全局网络对 `near/far/infinity/null` 的图像先验。几何模态的选择分数与该先验合并，并把 Hessian 无效、data rank 为零或无法形成局部 Laplace 分量的质量计入 unresolved/null，得到 `joint_state_probabilities`。最终有限点、无界方向或拒识决策使用联合状态与未解析质量，不由原始神经状态头或“最佳几何模态”单独决定。

## 4. 年轮前端与极细标注误差

完整协议将原始真值表示为带局部方差的亚像素中心线。像素软目标：

\[
y(\mathbf x)=\exp\left[-\frac{d(\mathbf x,\Gamma)^2}
{2(\sigma_{ann}^2(s)+\sigma_{pix}^2)}\right].
\]

前端结构定义了：

- 软年轮概率；
- 截断无符号距离场；
- 无向切线 `(cos 2theta, sin 2theta)`；
- 局部位置方差；
- 年轮实例嵌入；
- 缺陷类别。

当前已接入的年轮损失不是单一 Dice：

\[
L=L_{soft\ BCE}+L_{Dice}+\lambda_cL_{clDice}
+\lambda_d(L_{distance}+L_{variance})
+\lambda_oL_{orientation}+\lambda_eL_{instance}.
\]

[clDice](https://openaccess.thecvf.com/content/CVPR2021/papers/Shit_clDice_-_A_Novel_Topology-Preserving_Loss_Function_for_Tubular_Structure_CVPR_2021_paper.pdf)只作为低权重连通辅助，不能保证中心线位置、实例身份或由内到外顺序；[UAED](https://openaccess.thecvf.com/content/CVPR2023/papers/Zhou_The_Treasure_Beneath_Multiple_Annotations_An_Uncertainty-Aware_Edge_Detector_CVPR_2023_paper.pdf)支持显式建模多标注歧义，但不证明年轮法向误差独立或严格服从 Gaussian。上式软管及方差相加是局部矩匹配近似；标注者系统偏差、沿弧相关和拓扑多峰必须另外估计。

方差学习采用 [Stirn 等](https://proceedings.mlr.press/v206/stirn23a.html) 的 faithful heteroscedastic 原则：中心线均值始终接受未被方差缩小的距离损失，方差校准项使用 `residual.detach()`，且默认 `detach_variance_features=true`，使方差头不能通过共享 trunk 改变均值预测器。这样模型不能仅靠放大方差来逃避中心线拟合。关闭该开关只用于预注册消融，不能继续援引 faithful 理论条件。

**当前状态。** 代码已实现 polyline、逐点 `sigma_px`、软标签/距离/方向/实例栅格化，并训练年轮、距离、方差、方向和实例头。栅格器将 `sigma_px` 与单像素方框核的解析方差合并；`scripts/01_consensus.py` 对显式匹配的多标注弧做弧长配准、法向中位数/MAD 共识；灰度 `unknown_mask` 作为软有效权重 `1-mask` 使用，值 255 才完全排除，0 完全保留，中间值部分降权；bootstrap 模块可按 `scripts/03_infer.py` 指定的 AR(1) 相关系数注入沿弧法向漂移。拓扑分歧仍须保存为多个假设，defect head 尚无监督损失，相关结构尚未从多标注数据层次估计。

当前软栅格器用分块降低峰值内存，但每个输出像素仍搜索全体 polyline 线段，计算量近似为 `O(HW S)`，其中 `S` 是总线段数。超大训练画布、极密集年轮或大量多标注副本需要空间索引/局部包围盒等后续加速，不能由“分块”误解为已具有近线性局部搜索复杂度。

### 标注误差降低流程

1. 在原分辨率、放大状态下标亚像素 polyline；
2. 代表性子集至少做 3 位专家独立标注，并安排部分隔期重复标注和资深专家仲裁；
3. 先匹配年轮身份，再用含标注者偏差的层次模型沿法向估计偏移、局部方差和相关长度；
4. 平滑得到潜在中心线、`sigma_ann(s)` 和拓扑假设频率；
5. 用相邻轮中线截断软管，避免相邻细轮融合；
6. unknown/遮挡不作为负样本；
7. 按实测误差注入相关法向漂移、漏段、假边、断裂和错连；
8. 评价亚像素 Chamfer、HD95、容差 F-score、断裂率和错误连接率，不以 1 px IoU 为主指标。

## 5. 弧段图和可靠度先验

亚像素 ridge 经骨架路径与实例嵌入形成可变数量弧段。完整方案中，弧段图仅使用**不依赖候选髓心**的特征：长度、曲率、方向离散、标注/网络方差、缺陷重叠、端点质量、端点距离、切线一致和实例嵌入相似度。

目标图网络输出：

- `P(z_i=1|image, graph)`：弧段可靠度先验；
- 同环连接概率和 top-K 分组。

不把“与当前髓心不一致”放进先验网络，避免错误中心删除异议弧形成自证循环。

弧内像素高度相关。曲线按固定规范/物理间距重采样，几何似然按弧作为潜变量，并限制密集采样对整弧分类的过度放大。

**当前状态。** ridge/骨架弧提取和嵌入阈值聚类已接入推理。`ArcGraphNet`、构图和先验应用函数已有源码，但没有相应训练器、权重或 CLI 调用，也尚不会产生 top-K 分组。聚类 ID 只是临时实例标识，在未完成由内到外顺序恢复和闭环内部约束前，不应将它解释为生物年轮编号。

## 6. 定规化近场生长模型

共享仿射：

\[
A=\exp\begin{bmatrix}a&b\\b&-a\end{bmatrix},
\quad A=A^T\succ0,\quad\det A=1.
\]

变换坐标 `y=A^{-1}(x-c)` 后，以极坐标建模年轮。最内轮半径用 `softplus` 保证为正；按候选中心推断的顺序，后续轮直接参数化为

\[
r_{k+1}(\theta)=r_k(\theta)+m+\operatorname{softplus}[\alpha_k+g(\theta)+h_k(\theta)],
\]

因此基线在任意角度严格正增量，而不是在离散角点上加可被似然压过的软罚。最内轮删除一、二阶公共自由模态；公共二阶椭圆由 `A` 承担；跨轮偏差使用 Helmert 对比消除共享/逐轮系数的精确零空间。当前仍冻结每个初始化得到的一种年轮顺序；困难短弧的 top-K 顺序/DAG 仍是未接线部分，且带逐轮幅度的形态校正场可能需要额外的观察域不交叉审计。

这解决髓心平移与低阶形状吸收的定规问题。任意自由星形曲线仍可能让中心漂移，因此复杂度通过证据释放，而不是一开始全部开放。

## 7. 二维潜在形态扰动

代码实现允许源位置 `q_j` 位于图外的各向异性**逆向形态校正场**。定义观测点到基线点的可逆校正为

\[
\mathbf x_0=\mathbf x-\mathbf v(\mathbf x,k),
\]

而不是把它冒充为真实材料位移。其核为：

\[
\mathbf v(\mathbf x,k)=\sum_j a_{jk}K_{\Sigma_j}(\mathbf x-\mathbf q_j)\mathbf b_j.
\]

切线严格用 `(I-J_v)t` 变换，并对最小奇异值加防折叠约束。它有尺度、幅度和跨年轮平滑先验，并与零源模型共同参加证据比较。只能称为二维潜在形态场；单张 RGB 无法证明它是隐藏节，更不能恢复三维节轴或真实应力场。

**当前状态。** 原型支持零源/有源分支和图外源，分支权重依据是损失加 BIC 式复杂度近似，不是精确 Bayes evidence。可见节掩膜锚定、`H0/HV/HO/HU` 假设分类、源位置后验边缘化和用户可见的源摘要仍属验证协议。

## 8. 鲁棒优化

候选库包括：神经 mixture、APD 式法线最小二乘、成对交会、正负远场方向及对数距离网格。原型依次释放：

1. 圆/平行层＋轮偏置；
2. 共享仿射；
3. 定规化谐波和潜在扰动源。

令弧 `i` 的第 `j` 个标准化径向和切向残差为 `r^rad_ij,r^tan_ij`。当前异常分量不是宽 Gaussian，而是候选几何无关的均匀污染密度。忽略代码中限制密集采样影响的弧长幂次后，核心弧级似然为：

\[
p(D_i)=\pi_i\prod_j
\frac{t_\nu(r^{rad}_{ij})}{\sigma_{ij}}t_\nu(r^{tan}_{ij})
+(1-\pi_i)(2B)^{-2N_i}.
\]

其中 `B=outlier_scale`，均匀项在标准化残差窗口上为常数，因此被判为异常的弧不会通过一个宽 Gaussian 残差继续拉动髓心。代码把每弧有效点数截到预设上限后再缩放两类 log-likelihood，防止密集采样把弧分类置信度任意放大。

以 EM 更新软可靠度，用 LBFGS/Student-t 进行 IRLS 类优化；不按贡献值剪裁。多个实质不同的局部模态在损失窗口内保留，并用 BIC 式分数形成近似模态权重；文中不将它称为精确边缘似然。

硬删除只应在独立验证后启用，并同时满足：多初值/模型/bootstrap 均判异常、leave-one-out 支持、不是唯一方向信息、删除后数据秩不降、总比例不超过预注册上限。

## 9. 置信度和 Schur 边缘化

最终不使用冻结 EM 权重的 Hessian。代码对弧内/异常 mixture 的 log-sum-exp 边缘似然直接求二阶导。参数分为髓心图坐标 `p` 与全部干扰 `u`：

\[
H_p^{marg}=H_{pp}-H_{pu}H_{uu}^{+}H_{up}.
\]

使用谱阈值/线性求解，不用 ridge 伪造满秩。分别计算 data-only 与 data+prior 信息、秩、最小特征值和条件数。若只有 posterior 满秩，输出会标记 `prior_supported_only`；若 data 降秩，不生成虚假有限椭圆。

远场在 `(phi, rho)` 图中计算；`rho=0` 的完整输出应是方向扇区和距离下界。多模态分别 Schur，再保留 mixture。当前 JSON 保留模态、图坐标协方差和秩诊断，overlay 对远场只画方向箭头；扇区/下界的集合构造与渲染尚未接线。

当前实现通过自动微分构造“目标参数＋全部干扰参数”的稠密全 Hessian，再进行 Schur 边缘化。参数维数随年轮、谐波和潜在扰动源增加时，时间与内存会快速增长；这是一条强调审计正确性的研究实现，不应被当作稀疏大规模或实时求解器。

## 10. 弧段贡献

每条弧报告：

| 量 | 定义 | 解释 |
|---|---|---|
| 可靠度 `R_i` | 潜变量后验 | 是否像真实可用年轮 |
| 信息 `I_i` | `0.5(logdet+ H - logdet+ H_-i)` | 删除后可观测区域扩大多少 |
| 位置影响 | `c_all-c_-i` | 把髓心推向何处 |
| 冲突 | `-log p(D_i|D_-i)` 的证据近似 | 与其余证据冲突程度 |

完整 LOAO 定义要求删除弧的似然因子后，重估可靠度、年轮连接/形状、扰动参数和所有模型分支。若删除后降秩，标为“结构必需”；模型切换时不强行比较两个不同坐标图的 logdet。`I_i` 可为负，不截成零。

**当前状态。** `scripts/03_infer.py` 中 `EXACT_CONTRIBUTIONS=True` 会在固定 CNN 输出、弧提取和年轮分组后，为每段弧重跑几何 refiner，重估其他弧的软权重、形状和扰动参数。贡献量目前条件于选中模态，不会重跑密集网络、弧连接/top-K 分组，也不是完整 mixture posterior 的反事实距离。因此它应称为“条件几何层 LOAO”；全管线 LOAO 留作论文审计实验。

若有 `A` 条弧，精确 LOAO 至少触发 `A` 次额外多起点优化与 Hessian；`B` 次 bootstrap 还会触发 `B` 次完整几何拟合。两者当前都是离线诊断开关，运行时和峰值内存必须随弧数、模态数及干扰参数维数报告。

贡献只解释后验，不反向决定训练权重或剪裁。

## 11. Conformal 校准

完整协议要求冻结整条管线后，在按最高依赖层级（通常是树）独立的校准集上计算统一**标准化 mixture 非一致性分数**：

\[
A(I,c)=-\log\sum_m\pi_m\exp[-a_m(I,c)].
\]

这里不是把笛卡尔与极坐标密度相加；`a_m` 是各自图中由协方差/信息标准化后的无量纲距离，分支权重只作软最小值。近场 `a_m` 是二维 Mahalanobis；远场是方向＋逆距离；无穷远是方向误差＋逆距离单侧惩罚。任何固定、可交换的非一致性分数均可由 conformal 校准获得边际覆盖。令 `A_(k)` 为第 `k` 个顺序统计量，有限样本阈值为：

\[
k=\lceil(n+1)(1-\alpha)\rceil,\qquad
q=\begin{cases}
A_{(k)}, & k\le n,\\
+\infty, & k=n+1.
\end{cases}
\]

若顺序统计量索引为 `n+1`，阈值必须为无穷大；当前校准器已按此处理，不会用最大观测分数代替。因此对 `alpha=0.05` 至少需要 19 个可交换的独立组才可能得到有限阈值，而要稳定评估分层覆盖需要多得多的组。

同一独立组内多个圆盘/裁剪可取组内最大分数，形成该组内同时覆盖的保守版本；如果一棵树有多个圆盘，不能把圆盘冒充为独立组。总体 conformal 主要保证边际覆盖，仍需报告图内、近图外、远图外、近平行短弧、树种和设备分层覆盖。

**当前状态。** Python 推理/校准脚本已生成 mixture prediction、按组聚合 calibration score，并拟合/保存阈值；单点成员关系检查可直接调用 Python API `ConformalCalibrator.contains()`。推理脚本尚未将 `A(I,c)<=q` 反演成、序列化或渲染为校准椭圆/多峰区域/无界扇区；overlay 中的 95% 椭圆仍是局部 Gaussian Hessian 椭圆，不是 conformal 集。真实数据覆盖率也尚未报告。

## 12. 旋转等变的完整范围

`[-1,1]^2` 本身不等于旋转等变。完整协议要求训练和测试同时约束：

- 标量年轮/距离图的空间旋转；
- 双角方向场旋转 `2 alpha`；
- 近场 mixture 的均值和协方差；
- 远场方向；
- 状态概率不变；
- 后验区域、弧可靠度/信息不变，位置影响向量随旋转。

90°整数旋转用于严格数值测试；任意角度有插值误差，须扩大画布并使用 `valid_mask`。同一图像的旋转副本从不相乘为独立后验，也不作为独立 conformal 样本。

严格 push-forward 等变只适用于保持同一有效内容的双射群作用。若旋转或平移后重新裁剪，使弧段进入/离开视野，它已经是新的删失观测：髓心标签仍按几何变换，但后验宽度、状态质量和弧贡献不必保持不变。C4 输出一致性正则也不等同于严格群等变编码器。

**当前状态。** C4 loss 已覆盖年轮、距离、方差、缺陷 logits、双角方向、近/远混合头、状态和 infinity 方向。弧图、几何优化后区域、conformal 集、LOAO 信息/影响的等变回归测试尚未接线。`escnn` 只是可选依赖，当前没有严格群等变编码器实现。

训练数据混合全图 context 和原生尺度随机视图；原生视图把增强逆映射与矩形源坐标合成后直接从原图一次 `grid_sample`，不会先把整图缩到 `image_size` 再放大。推理的密集前端在原图分辨率上重叠 tiling，并另以固定方形 context 运行全局头。两者共享坐标和 `align_corners=False` 约定，但尚未完成多尺度 train/tiling parity、tile 拼接边界和跨分辨率概率校准的真实数据配对实验，因此不能仅凭实现一致就宣称数值等价。
