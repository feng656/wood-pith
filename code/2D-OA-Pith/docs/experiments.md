# 实验设计与论文验证

本文是**预注册式实验协议**，不是已完成的 benchmark 或性能报告。当前仓库提供若干单元/合成测试和核心训练—推理 Python 脚本/API；E0–E10 的数据构建、外部基线 adapter、全指标评测和真实数据结果尚待实施。

## 1. 数据划分

首先确定数据的**最高依赖层级**，通常是树，而不是圆盘或裁剪。同一树/原木的所有圆盘、裁剪、旋转、尺度和同一节的图内/图外匹配样本必须跟随母组。

`60% train / 15% validation / 10% calibration / 15% locked test` 只是独立组充足时的参考比例，不是对小数据集的固定建议。必须报告每个 split 的树数/独立组数，并在分组前给定随机种子和锁定清单。对 95% split conformal，少于 19 个可交换校准组时正确的有限样本阈值可能是无穷大；即使刚达 19 组，也不足以稳定宣称子组覆盖。小数据时可使用重复分组评估或交叉拟合来提高效率，但必须明确其覆盖保证与一次性独立 split conformal 的差异。

连续记录：`d/L`、髓心到边框有符号距离、方位角、闭环数、年轮数、总弧长、联合角覆盖、切线方向离散、曲率 SNR、邻轮完整度、缺陷、树种、设备和表面处理。

图外距离分析可分图内、近图外、`0.5–2`、`2–8`、`>8` 图宽，但主统计仍使用连续距离。

## 3. 基线

以下是论文比较集合。当前仓库尚未包含所有外部基线 adapter；实验时应在各自许可允许的独立环境中锁定 commit、数据预处理、超参数和权重。

- 共享/独立圆和椭圆；
- 法线最小二乘与 RANSAC；
- 局部曲率/抛物线外推；
- ACO、Hough、局部傅里叶；
- APD、APD-PCL、APD-DL；
- RGB 直接 xy、图内热图/DSNT、方向＋log 距离；
- DeepCS-TRD/INBD 年轮前端＋普通几何；
- 人工真值弧＋各几何模型；
- 完整 2D-OA-Pith。

完整圆盘方法不能通过把图外真值截边来隐藏失效。

## 4. 指标

下列是完整评测协议。当前 `metrics.py` 已覆盖点定位、对称 Chamfer/HD95、容差 precision/recall/F-score、经验覆盖和 AURC；断裂/错连、实例/顺序和整套等变评测仍待实现为统一 evaluator。

定位：毫米/图宽误差，中位/P90/P95，径向/切向误差，方向角、log 距离和灾难失败率。

细线：亚像素对称 Chamfer、HD95、容差 F-score、clDice、断裂/错连、实例和顺序准确率。

概率/拒识：覆盖率、椭圆面积、扇区角宽、距离下界覆盖、NLL、energy score、风险—覆盖和 AURC。

等变：

\[
e_{eq}=\|g^{-1}\hat c(gI)-\hat c(I)\|/L,
\]

并报告后验能量差、置信集合 IoU、贡献 Spearman 和影响箭头角误差。

统计以最高依赖层级（通常是树）为独立单位，使用配对 cluster bootstrap 或层次混合模型；不能把同一树/圆盘的几千裁剪当作几千独立样本。

## 5. 关键消融

1. 图外坐标截断 vs 不截断；
2. 各向异性拉伸 vs 等比例 padding；
3. xy vs 近/远/无穷远 mixture；
4. 硬 1 px mask vs 软亚像素不确定性；
5. 独立像素误差 vs 弧内相关误差；
6. 无弧图 vs 中心无关弧图；
7. 冻结 IRLS Hessian vs 边缘混合似然 Hessian；
8. 无形态场 vs 图外潜在源边缘化；
9. 数据增强 vs 输出/后验/解释完整等变；
10. Gaussian 椭圆 vs 多模态＋conformal；
11. 软降权 vs 激进硬剪裁；
12. 只缩小全图 vs 全局 context＋原分辨率 tile。

## 6. 成功标准

以下是待在锁定测试前预注册的判定原则，不是当前实验结论。正式研究必须在看锁定测试结果之前指定一个主终点、效果量阈值、灾难性失败定义、覆盖率容差、多重比较规则与组级置信区间，不用含糊的“显著更好”代替。

- 在信息充分分层达到预注册的中位/P95 髓心误差改善幅度；
- 在近平行短弧不虚报有限点，方向/拒识风险—覆盖优于基线；
- 95% 校准集在锁定测试总体达到预注册的覆盖容差，且远场子组无预定义的灾难性欠覆盖；
- data Hessian 指标能预测真实错误和退化；
- 高贡献弧删除达到预注册的后验扩大幅度，低贡献弧删除影响低于预注册阈值；
- 多标注误差模型降低细线 HD95 和下游髓心误差；
- 图外潜在源模型减少髓心偏移，但在不可归因条件下不虚报“节位置”。

## 7. 复现、功效与工程报告

每项正式实验必须额外保存/报告：

- 树级样本数、裁剪生成规则、空间注册和髓心真值协方差；
- 主终点的效应量目标、许可失败率和基于独立组的功效/精度分析；
- 数据/代码/权重版本、配置、随机种子、基线 commit 和许可证快照；
- 端到端命令、硬件/软件环境、运行时、峰值内存/显存、tile 规模和 LOAO 随弧数的复杂度；
- 无年轮/无信息负对照、图像分辨率分层，以及标注、拓扑、定位和校准误差的分解。

还必须单独审计三项当前计算瓶颈，而不能只报告 CNN 吞吐：

- 软栅格器的全局线段搜索随输出像素数和总线段数的扩展曲线；
- 全参数自动微分 Hessian 随年轮数、谐波阶数和扰动源数的时间/内存曲线，以及精确 LOAO、bootstrap 的乘法开销；
- 全图 context＋直接原图原生尺度训练视图与 tiled inference 的配对 parity，包括不同原生分辨率、tile 大小/重叠率、拼接边界、细轮尺度和概率校准漂移。

## 8. 必须诚实报告的失败条件

- 近平行短弧无法确定有限距离；
- 法线正负方向可双峰；
- 共享一阶 Fourier 与髓心平移严格混淆；
- 斜切、偏心、反应木和远图外扰动可能竞争解释；
- 任意星形闭环内部没有唯一几何中心；
- 单张二维 RGB 不能恢复三维节轴/真实应力场；
- 没有像素—毫米标定只能报告相对图宽；
- conformal 主要保证边际覆盖，不自动保证每个树种/设备条件覆盖。
