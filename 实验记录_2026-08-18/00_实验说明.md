## 实验目的

把 UruDendro 裁剪矩形数据集接入 `2D-OA-Pith` 髓心反演工程，首次在真实数据上端到端验证：
数据读取（图片 + 年轮 polyline + 髓心坐标）→ 烟雾测试 → 少量数据完整训练/推理 → 评估效果。

## 口径与假设（如实记录）

1. **无物理标定**：数据集无 mm/px，manifest 不写 `mm_per_pixel`，误差一律按**像素**报告
2. **pith_cov_px**：σ=8px 假设（真值来自圆拟合/人工标注）；曲线 σ=1.5px 假设
3. **pith_state**：near=0（髓心距 patch 中心 ≤ 边长）/ far=1（更远）；infinity/null 不分配（README：仅可辨识性实验或严格合成才可监督这两个状态）
4. **孤立裁剪科学边界**：未注册到完整截面的裁剪不能用于"远图外髓心"精度宣称；far 组误差仅作趋势参考，near 组才是可宣称口径
5. 训练期 near/far 重推导规则与适配器一致：‖pith‖ ≤ switch_radius(2.0) ⟺ 距离 ≤ 边长

## 结果摘要（持续更新）

| 阶段 | 结果 |
|---|---|
| 快速演示（纯几何，14 弧） | 1000×1000 patch，37 候选，30.7s；远图外髓心（~1.5k px）状态 NULL，误差 486px（仅验证链路） |
| 冒烟（1 轮训练） | 训练 255s / 推理 25s；预测 JSON 结构完整；未收敛模型被管线正确拒识（null） |
| 小数据训练曲线（本地 10 轮） | val total loss：ep0 5.065 → **ep6 4.655（最佳）** → ep8 4.877（末期余弦 lr≈1e-5 后回升）；训练因两次外部停止实际完成 9/10 轮，**评估用 best.pt = epoch 6**（数据上最优，补跑末轮不影响权重选择） |
| 小数据最终评估（本地） | **24/24 张被联合后验拒识（state=null）**——状态头仅 6 轮训练（状态 CE 仍 ~1.0），保守拒识是符合设计的未收敛行为；**但几何 mode 中心在 3 张髓心在图内的样本上误差 4 / 43 / 94px**，证明真实数据上链路正确、几何层有效。逐张明细见 `03_小数据运行\eval结果\eval_results.csv` |
| 服务器 150 轮（2026-08-19~20） | 完整跑完 150/150 轮：val total 5.015 → **2.934 @ ep112（最佳）**；state_ce 1.01 → **0.33**；ring_soft_bce 0.40 → 0.19。评估 24 张：**接受 1 张**（far 案例 166px，state=far/status=ok），23 张仍拒识——但此时状态头已充分训练，剩余拒识来自几何平稳性门槛（stationarity 1e-4 对网络提取弧仍不收敛）而非训练不足。near mode 中心 62 / 83px。明细见 `08_150轮最终结果\` |
