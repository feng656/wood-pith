## 解释类别定义(规则链:边界 → 指向一致度 → 弧长)
| 类别 | 判定 | 影响推断 |
|---|---|---|
| BOUNDARY_TRUNCATED | 子弧贴 crop 边界(≤5px) | 曲率约束弱,删除后影响小 |
| DEVIATING | mean|cos| < 0.70 | 指向冲突,删除后误差降 |
| SUPPORTING | mean|cos| ≥ 0.90 且弧长 ≥ 30px | 支撑共识,删除后误差升 |
| SUPPORTING_SHORT | mean|cos| ≥ 0.90 但弧长 < 30px | 支撑有限 |
| MODERATE | 其余 | 影响取决于邻段 |
| NO_CENTER | 最终估计无坐标(REJECT) | 无法计算 |
