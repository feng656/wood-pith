# ArcPith v5-slim 正式快速验证结果与指标去留决策

日期：2026-09-02  
数据范围：UruDendro4，T0/T2/T4/T6，共 4 棵 biological trees   
验证性质：按 v5-slim 协议执行的 rapid validation + exploratory shadow，不是 E3 calibration、正式 type-I/power、sealed test 或生产验收。

## 1. 结论先行

当前可以正式保留的最小指标集合是：

```text
硬正确性：replay/hash、h/t/frame/seam、barrier、search adequacy、firewall
核心定位：d_RP2、state-specific error、easy recovery、partial-arc paired delta
证据预算：parent-ring total budget、N_seg-equiv、重复/插值/fragment shift
状态拓扑：state agreement、component recall、unsafe FINITE_COMPACT miss、refinement flip
Preflight：unsafe pass、unnecessary reject、route stability、audit feasibility
Audit：firewall violation、null/large-effect response、powered/underpowered、uncovered boundary
风险路由：catastrophic POINT capture、false veto、incremental capture、cost per capture
工程与汇总：tree-level summaries、full-queue denominator、NOT_RUN/UNDERPOWERED、runtime/memory
```

当前可以明确降级或移出主线的内容是：

```text
M1-RPC 作为 runtime 主定位器
GT 附近 local bias audit 作为 Independent Audit 的替代品
搜索之后的 candidate_screen 作为 Preflight
未经校准的单一总分、小样本 p<0.05、采样点数作为独立信息量
Q8 contribution、Q9 Multi-FOV（Core 通过前不需要）
```

但以下事项仍不能宣称已经完成：严格同预算 B0/B1/B2/B3 的阶段 1 正式 KEEP、阶段 0 near-barrier/search adequacy 全套硬门、阶段 4 的 null/large-effect audit 功效、阶段 5 的 common-family-bias 风险边界、E3 校准和生产 POINT。

### 2.3 Equal-parent 修复后的证据

### 2.7 阶段 3：Profile 与五态

代码：[observability.py](D:/教务处实习/wood_preproject/树髓定位/代码/OC_ArcPith_RG_72h_algorithm_package_adjusted%202/OC_ArcPith_RG_72h_algorithm_package_adjusted/oc_arcpith_rg/observability.py)

这说明以下指标必须保留：

- POINT：坐标误差、`d_RP²`、profile support；

- MULTIMODAL：component count、mode recall、mode separation；

当前没有完整 F-POINT/F-AXIS/F-RANGE/F-MULTI/F-REJECT synthetic fixture 矩阵，因此 `RANGE_UNCERTAIN` 已补接口，但其最终阈值尚未证明必要。

### 2.8 阶段 4：Independent Audit

入口：[stage4_independent_audit.py](D:/教务处实习/wood_preproject/树髓定位/代码/OC_ArcPith_RG_72h_algorithm_package_adjusted%202/OC_ArcPith_RG_72h_algorithm_package_adjusted/experiments/stage4_independent_audit.py)

32 条 sentinel 结构试跑：

- firewall failures：0；
- `AUDIT_SUPPORTED`：0；
- `HOLDOUT_FAILED`：0；
- `HOLDOUT_UNDERPOWERED`：32。

这里的 `UNDERPOWERED` 是正确的保守结果：没有正式 sentinel response curve 时，不能把“候选比一个任意备选更好”当作 audit 通过。

因此：

- `E_fit | buffer | E_audit`：**需要**；
- firewall violation：**必须为 0**；
- `HOLDOUT_FAILED / AUDIT_SUPPORTED / HOLDOUT_UNDERPOWERED` 三分接口：**需要**；
- null rejection、large-effect rejection、powered proportion：**需要，但尚未完成正式功效验证**；
- 现有 GT-local `bias.audit`：**不能替代 Independent Audit**。

在 Independent Audit 完成 null/alternative 功效前，任何有限 `POINT` 只能标为 `RESEARCH_UNCALIBRATED`。

### 2.9 阶段 5：Common-family bias 与风险路由

现有真实结果显示 M1-RPC paired bias reduction 的中位数为 `7.25e-12`，tree pass fraction 为 0；因此 M1-RPC 不应继续作为 runtime 主模型。

必须保留的风险指标：

- `catastrophic POINT` capture；
- false veto；
- audit-only 到 audit+bias 的 incremental capture；
- 每新增捕获的计算成本；
- `NOT_RUN/UNDERPOWERED`；
- 未覆盖 catastrophe 类型。

尚未完成的部分：ellipse、center drift、低频 deformation、mixed centers、common tangent bias 的系统 synthetic 压力面，以及 cheap scatter/S1 的增量比较。因此目前只能：

- 保留 M0 作为描述性 baseline；
- 将 M1-RPC runtime route 降级为 `REMOVE RUNTIME`；
- 对未定义风险边界的 stratum 使用 `POINT_BLOCKING/HARD_REJECT`；
- 不声称已有 family-bias 解决方案。

### 2.10 阶段 6：四棵树 shadow

四棵树只能支持 exploratory/shadow：

- 可报告 full-queue state distribution、route、失败定位、runtime 和 tree-level map；
- 不可估计正式总体准确率、正式 type-I/power 或 calibrated POINT；
- 新 biological trees 或独立 full-section/FOV reference 到来后，应追加 manifest 并创建新 rapid version，不与旧四树结果拼成校准结论。

## 3. 最终指标去留表

| 指标/参数 | 决策 | 依据 |
|---|---|---|
| `d_RP²` | **需要** | 统一 finite/infinity projective 比较；阶段 1 四树方向稳定 |
| finite 坐标/物理误差 | **需要** | `d_RP²` 不能表达实际位置尺度 |
| AXIS modulo-π 方向误差 | **需要** | AXIS 没有有限距离 |
| RANGE containment/width | **需要** | bounded region 不能压成单点 |
| MULTIMODAL component/mode 指标 | **需要** | 防止静默选择单一错误模式 |
| easy recovery | **需要** | 阶段 1 核心安全门 |
| partial-arc paired delta | **需要** | 判断 S0 独立增量 |
| parent-ring total budget | **需要** | equal-parent 核心约束 |
| 采样点数量 | **不需要作为独立信息指标** | 不能冒充 parent-ring 独立证据 |
| `N_seg-equiv` | **需要作为相关性修正候选** | 防复制/插值虚增支持；仍需强相关验证 |
| P0/P1 coverage/count | **需要** | 便宜、candidate-free、安全路由 |
| P2 `F_geom` | **候选保留** | 已识别 AXIS-only，但尚无完整增量证明 |
| P3 correlation class | **暂不需要作为主线** | 当前 P3 与 P2 路由相同 |
| profile grid/refinement | **需要** | topology 与危险漏检检查必需 |
| `support_delta`、POINT/AXIS/RANGE cutoff | **暂不冻结** | 最终阈值必须 E3 calibration |
| `RANGE_UNCERTAIN` | **需要状态语义** | 接口已补；最终判定阈值未校准 |
| E_fit/buffer/E_audit split | **需要** | reliable POINT 的证据防火墙 |
| audit firewall | **必须** | 当前 0 failures，但仍需 candidate-switch attack |
| null/large-effect audit response | **需要** | 尚未完成正式 sentinel 曲线 |
| powered/underpowered | **需要** | 32 条结构试跑均保守标 UNDERPOWERED |
| GT-local bias audit | **不能替代 Independent Audit** | 使用 GT/同一证据，不是 holdout 反证 |
| M1-RPC runtime | **不需要** | 现有 reduction `7.25e-12`，未达到预注册目标 |
| cheap scatter/S1 | **候选，尚未定** | 需在 common-bias synthetic 上证明增量 |
| catastrophic capture/false veto/cost | **需要** | 风险路由的直接目标 |
| 单一总分 | **不需要** | 安全、误差、覆盖、成本不可未经校准合并 |
| 小样本 `p<0.05` | **不需要** | rapid validation 不以显著性替代机制/安全判断 |
| tree-level 汇总 | **需要** | biological tree 是独立单位 |
| full denominator/NOT_RUN/UNDERPOWERED | **需要** | 防止缺失证据被算成通过 |
| Q8 contribution | **当前不需要** | Core 通过后的可选扩展 |
| Q9 Multi-FOV | **当前不需要** | 不能用于挽救单 FOV Core |
